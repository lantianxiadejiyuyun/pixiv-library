后端测试使用临时数据库，不在生产应用容器内执行。覆盖平台适配器、队列与账号分工、并发租约、权限边界、数据导出、阅读进度、收藏与历史等流程。小说自动封面专项覆盖扫描容量与游标、暂停、去重、重试间隔，以及正文、人工资料和进度保留。

Pixiv 账号分工验证包含主账号目录发现、图片下载、作品详情与小说正文、作者资料，以及旧任务的角色兼容和并发占用；使用不同模拟身份实际执行任务验证。Kemono 覆盖接口解析、分页、图片／正文／视频去重和完整性，以及真实两阶段队列到独立存储路径的 11 项合成内容集成测试。平台 API 覆盖配置持久化、设备再次验证管理员密码、地址与重定向边界、五个平台请求和哔咔／JM 页面登录接线。

视频服务验证 MP4／M4V／MOV／WebM 容器识别、损坏文件拒绝、GET／HEAD、Range 206／416、设备授权、混合文件顺序和播放比例进度。容器识别不等于完整视频解码或转码。

Flutter 新增 3 项平台 API 设置测试及 8 项原生视频平台模拟测试，覆盖管理员验证失败保留设备绑定、恢复播放位置、仅当前文件创建播放器、重试、全屏共用播放器、后台暂停、离页保存和初始化取消。浏览器在独立临时页面使用合成 VP8／WebM 视频，验证实际解码、播放、拖动、视频与文字切换、重新挂载后的进度恢复及 Range 请求；没有访问或改动真实书库。

手机后台新增 4 项服务端测试，覆盖管理目录授权、现有管理写操作的入口完整性、原生字段解析和管理员 Cookie 管理路径，普通扫码设备仍被拒绝。App 新增 9 项回归，验证管理员与阅读凭据分离、登录／退出、禁止跟随重定向、设置读取失败不覆盖、类型化保存、删除确认、代理订阅选择和 multipart／APK 原始流上传。系统文件选择／保存窗口尚未做手机真机验证。

Flutter 测试覆盖绑定与凭据、资源请求边界、漫画／小说阅读、分页与位置恢复、收藏分组、独立评分、作者目录、标签导航、瀑布流双击查看及在线更新。独立评分回归包含未收藏评分、取消收藏保留评分、清除评分、保存失败重试、迟到详情响应及保存中关闭弹层；Web 同样验证收藏／评分互不覆盖及迟到响应。另使用独立临时服务和合成内容完成真实 HTTP 绑定、读取、进度保存、权限限制与解绑联调。

图片缓存覆盖同图请求合并、跨实例磁盘复用、授权隔离、过期刷新、内存与磁盘限额、后台写入预算、清理后迟到请求、损坏数据重试、存储不可用及授权失效。小说性能用合成长章节验证：2400 段只挂载不到 40 段；约两万字符单段分块后的总高度与原完整排版误差小于 0.01 像素，并验证字号、屏宽和文字缩放变化后的比例恢复。已完成 390 像素宽原生控件预览；此结果不等于手机真机帧率测试。首次打开长章节仍需分帧计算完整排版，特殊双向文字或控制字符段落保留整段排版上下文。

## 尚未验证或未实现

- Android 真机安装、摄像头扫码，以及各手机品牌的安装权限流程仍需验证；iOS 需 macOS、Xcode 和签名环境进行构建与真机测试。
- 手机当前从绑定服务器读取内容，完整书籍保存到手机后的断网阅读尚未实现。
- E-Hentai、PicACG 和 JM 的真实账号流程尚未完成全面联调；Pixiv 的账号权限、访问限制及接口变化需按实际账号确认。
- Kemono 已验证公开版本接口可访问及合成响应的完整导入流程，真实作品下载尚未全面联调。Android 视频测试采用原生平台模拟，具体手机与编码组合仍需真机验证；不支持压缩附件、外部嵌入媒体或自动转码。
- NAS 的 SMB/NFS 权限、断线恢复和不同 CPU／驱动组合仍需在目标设备验证；Intel GPU 算子支持与性能取决于硬件及驱动，CPU 提供回退路径。
- AI 汉化使用合成模型响应验证了接口流程，尚未据实际模型评估翻译质量；SauceNAO 有效密钥下的真实图片匹配仍需验证。
- 长期大规模增量同步、压力负载及平台接口变更不由当前单次测试覆盖。
