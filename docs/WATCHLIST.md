# Pixiv 连载追更和作者下载

Web 侧边栏与 App 侧边栏的「连载追更」分别展示漫画、小说系列，可搜索、筛选未读更新、查看系列目录和标记本地已读。

## 官方追更列表

主账号同步关注作者后，会顺带创建独立的追更列表同步任务。已有账号升级后可在追更页点击「同步主账号追更」。主账号负责读取漫画与小说追更列表以及系列目录，正文继续使用作品内容账号、图片下载账号等现有分工。同步和系列检查都进入「作者与订阅检查」队列，不占手动下载队列。

首次同步后默认每 60 分钟再次检查，可在 Web 追更页面或 App 后台修改间隔、暂停自动同步。发现新系列或最新章节变化时，创建系列目录检查任务；每个系列可单独暂停或选择自动下载正文，默认只获取封面和资料。App 阅读页面提供列表、目录和已读操作，下载策略在 Web 或 App 管理工作台修改。

追更数据按主账号隔离。切换主账号不把旧账号的列表当作新账号列表；请求期间主账号更改时，不保存旧请求结果。两类列表的全部分页成功后才替换远端状态，失败保留原列表。从 Pixiv 移出的系列只移出当前列表，本地作品和本地设置保留。修改本地暂停、自动下载及已读状态不会修改 Pixiv 的远端追更设置。

当前一次同步最多读取 1000 个小说系列、500 个漫画系列，按固定官方接口校验分页。系列目录沿用最多 1000 篇、50 页的读取边界；不完整目录保留已有成员并显示实际完整性。无法读取、暂停及队列失败会显示原因，不报告为已完成。

「未读更新」通过最新章节编号与本地明确标记的已读编号比较。首次导入尚未标为已读的系列会显示更新；该标记不代表 Pixiv 的阅读状态，也不替代每章实际阅读进度。

功能含义参考 [Pixiv 官方追更列表说明](https://www.pixiv.help/hc/en-us/articles/900004833123-What-is-Watchlist)。接口结构通过授权主账号的只读请求核对，未向 Pixiv 写入追更或收藏操作。

## 作者作品与公开收藏分别下载

作者主页提供两个独立选项：下载作者发布的作品、下载作者公开收藏。关注订阅编辑页和 App 作者主页也提供相同选项。关闭时仍获取对应封面和资料，开启时缺失正文进入自动下载队列；不会递归关注收藏作品的作者，不自动下载他人的私密收藏。

同一作品同时属于作者作品与公开收藏时，任一对应选项启用即可下载，仍复用同一任务。旧订阅未设置新字段时，两个选项均沿用原有「自动下载」值，升级不会替用户开启下载。对原统一开关的旧客户端更新仍按统一设置处理。已排队任务不因选项关闭而自动取消，可在任务中心单独取消。

手机阅读凭据可修改指定作者的两项下载选择，但不能借此读取平台凭据、修改账号分工或访问完整后台订阅接口。

## 关注作者作品的默认下载开关

Web「内容来源 → Pixiv」新增「关注作者作品自动下载」，默认关闭。App「后台管理 → 平台与账号」也提供读取和修改此设置的原生表单，支持动态管理目录的现有 App 无需重新安装。

开启后，已经同步为作者订阅的关注以及之后新增关注，都会在检查更新时按订阅范围默认下载作者发布的插画、漫画和小说。未单独设置过作品开关的作者继承此默认值；作者主页或订阅中已明确开启／关闭的选项优先。作者公开收藏、主账号自己的收藏、系列追更的下载开关继续独立生效。

首次开启会让已启用且继承默认值的作者等待下一轮检查；由现有每批 20 个作者的调度器逐步检查，缺失正文进入自动下载队列，复用已有任务和已保存文件。仍遵守采集暂停、各队列与各账号并发，以及平台请求限制。当前自动检查读取最新一页，不因开启此选项而回填全部历史作品。关闭后不取消已经入队的任务；单个作者明确开启的下载选择也不被覆盖。

设置接口为管理员认证的 `GET/PUT /api/pixiv/follow-download-settings`，写入 `{"enabled": true}` 或 `false`。普通扫码阅读凭据不能修改全局策略。作者订阅 `download_works: null` 表示恢复默认值；旧客户端明确提交统一关闭时，会保存为单个作者的关闭选择。

## 手动下载与采集暂停

「暂停采集」只控制自动下载、详情解析和作者／订阅检查。手动下载的起始封面／详情和后续正文都属于手动下载队列，不受该总开关控制；仍遵守自身暂停、队列并发、账号并发、请求限速与平台返回的等待时间。修改统一网络并发仍沿用现有行为，同时设置各网络队列上限。
