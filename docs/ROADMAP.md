- Pixiv 授权回调自动接收与移动端便利性；当前使用官方网页登录后手动复制授权码。

- 历史补全与增量游标：最新检查与历史回溯分离，持久游标、重叠窗口、断点续跑。

- 其他平台原生关注与收藏实体；Pixiv 已提供分账号的分页作者／收藏目录，收藏定时增量同步及长期更新游标仍待实现。
- 独立 GPU 电脑执行任务、节点认证、心跳、GPU 资源调度。
- 自定义角色参考图库、多人页面分区、未知角色聚类及人工命名。
- SauceNAO 有效密钥与真实漫画截图匹配联调；已完成文字角色查询、单张图搜与人工确认流程，当前网络的匿名图搜被上游拒绝。
- 目标 Intel 核显／NAS 的 GPU 实际推理和性能验证；CPU 与加速失败回退已用真实 WD 模型验证。旧 Intel GPU 的 legacy 驱动镜像尚未提供。
- OCR、竖排漫画识别、多语言全文检索，以及基于模型的文章语义分类。
- PDF/EPUB 导入和专用阅读器，保留章节、插图、文本位置。
- Flutter 真机覆盖升级、未知来源安装授权、摄像头扫码和阅读验证，以及 iOS 签名／设备验证；原生界面、扫码授权协议、Android 正式签名安装包、静态分析及测试已完成。
- 手机整书离线下载、容量管理及阅读进度冲突合并；当前 App 和 Web 阅读仍需要访问书库服务器。
- 多用户书架与权限、全文 ngram 索引、向量检索、大书库分页/聚合性能优化。
- 在真实 NAS 上验证中断、重命名、目录权限、ARM 镜像与吞吐。
- 备份恢复演练、后台健康监控、可审计文件回收和完整性巡检。

后续阶段用实际书库样本分别测量角色识别、未知拒识、R18 误报/漏报及处理时间，模型分数不直接等同真实置信概率。
